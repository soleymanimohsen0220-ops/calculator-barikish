# Calculator Barikish

Simple calculator built with Kivy — Android-ready.

## Features
- Four basic operations: + − × ÷
- Parentheses
- Percentage
- Dark/Light theme toggle
- History panel
- Circular = button
- Mobile-friendly layout

## Build APK

The APK is built automatically by GitHub Actions. Go to the **Actions** tab to download it.

## Local development
```bash
pip install kivy
python main.py
```
